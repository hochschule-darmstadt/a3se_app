# Generated Types

`schema.ts` is generated by `openapi-typescript` from
`../../generated/openapi.json` (`npm run generate` in this package, or
`npm run api-client:generate` from the repository root, which also
regenerates the OpenAPI export first). Never edit it by hand -- it carries
its own "do not make direct changes" header. `client.ts` in the parent
directory is the small hand-authored facade built on top of these types.
