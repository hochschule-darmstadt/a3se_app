# Customer Portal Home Image Assets

The four master JPEGs and nine responsive renditions derive from exactly four
accepted synthetic source images: one VIEW-C-001 header image and Brazil,
Peru, and Chile quick-link images. Their provenance, review, and usage limits are
authoritatively recorded in [the UX imagery record](../../../../../../docs/requirements/ux/imagery/imagery.md).

They are static portal presentation assets, not seeded catalogue/entity data.
