# Technology Stack Guidance

- Status: draft
- Owner: Engineering
- Last reviewed: 2026-07-21

This area is intentionally empty of stack choices. Populate it only after an accepted ADR selects a technology.

For each selected technology, add a focused guide covering:

- intended role and version policy;
- repository structure and idioms;
- secure defaults and prohibited patterns;
- build, formatting, static analysis, test, and dependency commands;
- observability, operations, and upgrade policy;
- authoritative documentation links;
- task-specific agent skills or checklists, when they add value beyond normal project guidance.

Technology guidance must link back to its ADR and must not override product requirements.
