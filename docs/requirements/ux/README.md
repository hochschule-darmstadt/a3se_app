# User Experience Requirements

- Status: draft
- Owner: Requirements
- Last reviewed: 2026-08-17

This area holds user-experience requirements and supporting design artifacts. UX artifacts are hypotheses until supported by stakeholder evidence and validated against relevant use cases, accessibility needs, and quality requirements.

Use a human-centred progression: actor and context-of-use research; task flows and journey hypotheses; low-fidelity wireframes focused on information, actions, states, and recovery; accessible prototypes after technology selection; and documented usability and accessibility evaluation. Do not select a visual design platform solely for attractive generated output.

UX work consumes the [use-case activity-diagram pilot](../use-cases/activity-diagram-pilot.md) as upstream interaction evidence. The diagrams remain requirements views governed by the [activity-diagram standard](../../governance/standards/use-case-activity-diagrams.md), not UX outputs.

- [View Navigation Maps](navigation-maps/): proposed customer-facing and staff-facing views, traversal, traceability, and open questions
- [Wireframes](wireframes/): annotated customer and staff interaction and state concepts derived from the navigation maps
- [Shared UI Design System](design-system/): semantic foundations, customer/staff profiles, evidenced component contracts, governance, and a browser-reviewable catalogue
