# Design System Structure Reference Review

- Status: draft
- Owner: Requirements/UX
- Last reviewed: 2026-08-14

## Provenance and limitation

The public [Owl Listener designer-skills design-systems collection](https://github.com/Owl-Listener/designer-skills/tree/main/design-systems) was inspected on 2026-08-14 at stakeholder request. It is a collection of AI-oriented skills, not a product design system or project requirement. Its organization is used only to challenge completeness.

## Useful structure

The collection separates design tokens, component specifications, theming, reusable patterns, documentation, accessibility, localisation, naming, icons, motion, and governance. Its token guidance distinguishes raw values, semantic aliases, and component-scoped values; its component guidance covers anatomy, variants, states, behaviour, accessibility, and usage; its theming guidance supports shared foundations with profile mappings.

## Deliberate simplification

This project will not reproduce the plugin, command, or eleven-skill structure. The applicable ideas are collapsed into four parts in one design-system topic: foundations, customer/staff profiles, evidenced components and patterns, and lightweight governance. Separate icon, motion, naming, localisation, documentation, accessibility, and versioning subsystems are added only if concrete needs outgrow those sections.
