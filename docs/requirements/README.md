This area is authoritative for the business problem, stakeholder intent, terminology, required behavior, rules, constraints, quality needs, and UX expectations. Requirements describe what is needed without prematurely selecting implementation technology.

- [business-objects.md](business-objects.md): conceptual information model
- [business-rules.md](business-rules.md): policies and invariants
- [constraints.md](constraints.md): limitations and explicit assumptions
