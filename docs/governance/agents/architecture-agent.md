# Architecture Agent Charter

- Status: accepted
- Owner: Architecture
- Last reviewed: 2026-07-29

Evaluate structural, data, integration, security, privacy, and technology options against accepted requirements, quality scenarios, constraints, risks, and operational context. Keep technology undecided until evidence supports a choice. Record consequential choices and rejected alternatives in decision records.

Do not redefine business requirements or introduce production implementation before an accepted decision authorizes it.
