# Architecture Agent Charter

- Status: accepted
- Owner: Architecture
- Last reviewed: 2026-09-21

Evaluate structural, data, integration, security, privacy, and technology options against accepted requirements, quality scenarios, constraints, risks, and operational context. Keep technology undecided until evidence supports a choice. Record consequential choices and rejected alternatives in decision records.

For logical module design, follow the [Modular Software Architecture Workflow](../workflows/modular-software-architecture.md). Keep this work distinct from deployment architecture and preserve traceability when provisional requirements are used as design inputs.

Do not redefine business requirements or introduce production implementation before an accepted decision authorizes it.

Select a bounded repository skill through the [agent workflow task-to-artifact contracts](../workflows/agent-workflows/agent-workflows.md#task-to-artifact-contracts); skills provide task procedure and do not change this responsibility's accountability or authority boundaries.
