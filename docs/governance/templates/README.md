# Templates

- Status: accepted
- Owner: Management
- Last reviewed: 2026-07-29

- [decision-record.md](decision-record.md): general consequential decision record
- [task.md](task.md): concrete lifecycle or engineering work
- [feature.md](feature.md): proposed feature or lifecycle change
- [bug.md](bug.md): observed defect or specification deviation
- [use-case.md](use-case.md): Cockburn-style use case

These Markdown files are the canonical templates for agents and repository work. The corresponding GitHub Issue Forms in [`.github/ISSUE_TEMPLATE`](../../../.github/ISSUE_TEMPLATE) implement `task.md`, `feature.md`, and `bug.md` for manual entry. Keep both representations aligned in the same change.

Templates support consistent evidence; they do not replace accountable judgment. Issues organize work and findings; they do not become authoritative requirements or decisions merely by being created or moved on a board.
