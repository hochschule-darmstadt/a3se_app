# Templates

- Status: proposed
- Owner: Management
- Last reviewed: 2026-07-31

- [decision-record.md](decision-record.md): general consequential decision record
- [epic.md](epic.md): scope associated with one domain
- [feature.md](feature.md): one use case within an epic
- [story.md](story.md): independently reviewable use-case slice
- [task.md](task.md): concrete lifecycle or engineering work
- [bug.md](bug.md): observed defect or specification deviation
- [use-case.md](use-case.md): Cockburn-style use case

These Markdown files are the canonical templates for agents and repository work. The corresponding GitHub Issue Forms in [`.github/ISSUE_TEMPLATE`](../../../.github/ISSUE_TEMPLATE) implement `epic.md`, `feature.md`, `story.md`, `task.md`, and `bug.md` for manual entry. Keep both representations aligned in the same change.

Templates support consistent evidence; they do not replace accountable judgment. Issues organize work and findings; they do not become authoritative requirements or decisions merely by being created or moved on a board.
