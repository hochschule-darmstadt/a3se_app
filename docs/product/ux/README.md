# UX, Accessibility, and Wireframes

- Status: draft
- Owner: UX/Product
- Last reviewed: 2026-07-22

Use human-centred design informed by stakeholder and user research. Link journeys, wireframes, and UI concepts to personas/proto-personas, actor goals, use cases, and acceptance evidence.

## Artifact progression

1. Research evidence and explicitly labeled proto-personas.
2. Task flows and journey hypotheses.
3. Low-fidelity wireframes focused on information, actions, states, and error recovery.
4. Accessible interactive prototypes after UI technology selection.
5. Usability and accessibility evaluation with documented findings.

Wireframes are design hypotheses, not requirements. Prefer simple reviewable artifacts; do not select a visual design platform solely for attractive AI output. Record accessibility expectations early and apply the current applicable WCAG version when implementation begins.
