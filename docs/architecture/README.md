# Architecture and Technology

- Status: draft
- Owner: Architecture
- Last reviewed: 2026-07-21

No stack is selected. Architecture begins with business goals, quality scenarios, constraints, domain boundaries, risks, and team context.

## Decision sequence

1. Accept architecture drivers.
2. Identify candidate styles and technologies.
3. Define evaluation criteria from requirements.
4. Use time-boxed evidence or spikes for material uncertainty.
5. Record the decision and rejected alternatives in an ADR.

See [technology-evaluation.md](technology-evaluation.md) and [../decisions/README.md](../decisions/README.md).
